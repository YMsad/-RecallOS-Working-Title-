# RecallOS V0.3.0 Release Notes

发布日期：2026-08-15

## 版本主题

**下一代学习流程：阅读 → 验证 → 深化。**

V0.2 系列解决了「对话感」与「为什么追问」的表层体验，V0.3.0 则把追问从「四层提问 → 判对错」重构成一条真正贴近人类学习方式的完整链路：先自己读，再被检验是否真懂，最后在五个方向的深化追问里彻底打通底层逻辑。

## 核心变化

### 新学习流程（默认启用）

```text
📖 阅读原文（先自己读，不被问题打断）
  ↓
🧠 验证理解（AI 出一道验证任务，检验你是真懂还是背出来的）
  ↓
🔍 深化追问（5 层递进：再验证 → 联系 → 反事实 → 行动 → 第一性原理）
  ↓
🔗 知识连接 + 📊 每日总结
```

- 首页不再强制设置「有基础 / 零基础」与开场偏好，直接开始学习，降低启动成本；
- 学习页顶部有阶段指示器（阅读中 / 验证理解 / 深化追问 / 已完成 / 需要重新学习）；
- 验证阶段答不上来可一键「大白话解释」，只降难度、不改题目、不替你想；
- 连续 3 次未通过验证 → 标记「需要重新学习」，引导回看原文后再试；
- 深化追问没有对错，重在输出真实思考（AI 不判分，只记录与推进）。

### 「继续学习」精确恢复

新流程的会话状态（阶段、验证任务与作答次数、深化进度、全部对话记录）现在持久化到本地数据库。

- 中途关闭应用后，首页「继续学习」会**精确回到上次中断的阶段**：
  - 阅读阶段 → 回到原文页；
  - 验证阶段 → 恢复任务、已作答次数与历史回答；
  - 深化阶段 → 屏幕上那道没答完的深化问题原样还原，绝不重复生成或跳过。
- 旧四层追问流程保留，设 `RECALLOS_NEW_FLOW=0` 即可回归。

### 底层

- `core/session.py`：新增 `restore_session()` 与深化问题持久化；`LearningSession` 扩展 `stage` / `flow` 等状态，旧方法以 `@deprecated` 保留未删。
- `core/database.py`：concepts 表新增 11 个字段（阶段、验证、深化），兼容旧库自动迁移。
- 测试：新增会话恢复（6 项）与 UI 恢复（2 项）用例，全量 pytest 通过。

## 兼容性

- 已有本地数据库（V0.2.x）无需手动迁移，首次启动自动补列；
- 旧流程 UI 与代码完全保留，仅通过环境变量切换；
- Windows 桌面版重新打包（`dist\RecallOS.exe`），同样包含新流程。

## 已知限制 / 下一步（V0.3.1）

- PDF / EPUB / 网页导入解析仍未实装（推迟到 V0.3.1）；
- 深化追问的 5 个方向目前由 AI 直接生成，少量用户反馈「问题差不太多」，后续按 text_type 做差异化。
