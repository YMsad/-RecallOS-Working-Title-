RecallOS UI设计文档 V0.1（纳瓦尔版）
一、设计原则
原则	说明
内容即界面	没有任何装饰元素，所有空间留给“问题”和“思考”
每一步只做一件事	每个页面只有一个操作按钮，防止分心
渐进式披露	不一次性展示所有功能，跟着用户节奏逐步出现
温暖但克制	颜色只用暖灰+琥珀色点缀，像纸质书+台灯的氛围
无压力设计	不显示进度条、不显示“还剩多少”，只显示“今天学到了什么”

交互逻辑（关键）：

用户行为	系统反应
输入回答，按回车	AI判断回答方向是否正确
回答正确	显示“✓ 对！”→ 继续追问下一层
回答偏差	显示“🤔 再想想……”→ 给一个提示→ 让用户重答
回答“不知道”	显示提示→ 让用户再试一次
连续3次答不上	AI给出参考答案 → 记录“模糊” → 跳到下一个问题
用户按“?”	显示一句提示（不是答案，是方向引导）
设计理念：

AI从不直接给答案，只给“方向提示”

用户答对了，获得“我自己想出来的”成就感

用户答错了，不惩罚，只是“再试一次”

四、设计规范
颜色
用途	颜色	色值
背景	暖灰白	#FDFBF7
主要文字	深炭色	#1A1A1A
次要文字	中灰色	#6B6B6B
强调/品牌	琥珀色	#D4875E
正确反馈	柔绿	#6B8F71
模糊/待定	柔黄	#D4A85E
边框/分割线	极浅灰	#EFEBE4
字体
用途	建议
主字体	系统默认（无衬线）或思源黑体
字号-标题	24px（“今天想弄懂什么？”）
字号-追问	18px（AI的问题）
字号-正文	15px（用户回答、提示）
字号-辅助	13px（底部提示、日期）
行高	1.6（保证可读性）
间距
页面边距：32px

模块间距：24px

元素间距：12px

输入框内边距：16px

交互反馈
场景	反馈方式
回答正确	文字变绿色 + “✓” 符号，0.3秒后自动进入下一题
回答偏差	文字变琥珀色 + “🤔” 符号，显示提示
卡住按“?”	在输入框下方淡入提示文字
保存成功	底部短暂显示“已保存”，1.5秒后淡出
错误	红色边框闪烁，显示具体错误信息
动画原则
不炫技：所有动画时间 < 0.4秒

有目的：只在状态切换时使用（如“回答正确→进入下一题”）

无干扰：没有弹窗、没有模态框、没有Loading转圈（用文字提示代替）

五、响应式设计（MVP）
平台	处理方式
Web（桌面）	居中卡片，最大宽度640px，模拟“对话感”
命令行（CLI）	纯文字，用空行和缩进制造呼吸感
移动端浏览器	自适应，卡片占满屏幕宽度
MVP只做Web和命令行，不做原生App。
