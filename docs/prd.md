# RecallOS 产品需求文档（PRD）

> 版本：V1.0（对应代码 v1.0）· 更新日期：2026-08-17
>
> 本文档基于当前代码实现编写，所有功能均可在 `app.py`、`core/`、`cli/` 中找到对应实现。

## 1. 产品概述

**一句话定位**：RecallOS 是一个基于苏格拉底追问法的 AI 学习伴侶，打开即用，不需要配置任何东西。

**产品核心主张**：AI 不替用户思考，只逼用户输出。每一次追问都引导用户自己说出答案，而不是把答案喂给用户。

### 1.1 解决的问题

- 传统「背概念」式学习记不住、用不上。
- AI 直接给答案，用户没有真正思考，学完就忘。
- 缺少复习调度，学完即丢。

### 1.2 答案思路

| 问题 | 方案 |
| --- | --- |
| 记不住 | 每段阅读后用自己的话总结一句；验证时默闭卷作答；看完即「验证过即完」 |
| 学用脱节 | 验证任务（而非复述）检测真实理解；深入追问把概念推进到「行动 / 第一性原理」 |
| 学完就忘 | 间隔重复（2/4/…/7 天），AI 用「昨天你搞懂了什么」的钩子来检验 |
| 不想回来 | 连续学习天数（streak）、每日总结、首页复习/继续学入口 |

## 2. 目标用户与核心场景

**目标用户**：想要「真正搞懂」一个概念、且愿意自己开口输出的学习者（零基础即可）。

**核心场景**：

1. **首次打开、毫无头绪**：首页推荐一个内置精选概念（机会成本/复利/幸存者偏差…），点一下即可开始，零输入直接学习。
2. **想学自己的概念**：首页「自定义」粘贴一段原文，立即进入学习。
3. **学了一个概念**：跟着「阅读 → 验证」走完，自动生成每日总结，明天由 AI 追问检验。
4. **几天之后**：首页出现「今日复习（N）」，用上次的 `tomorrow_hook` 检验还记得多少。

## 3. 核心原则（产品红线）

1. **AI 不替用户思考，只逼用户输出**——所有交互都以「用户必须说出点什么」为前提。
2. **每一层追问都引导用户自己说出答案**——绝不直接给出答案，只给方向性提示。
3. **新增功能必须回答**：「它是否让用户更容易『搞懂』？」——无法回答该问题时不加。
4. **用户觉得无聊就调整对话风格，而不是减少追问**——追问本身不可删，只允许换语气。

## 4. 学习流程（核心用户旅程）

### 4.1 新流程（V0.3.0 起，当前默认）

```
reading → validation → (gap 时) intervention → complete / relearn
```

| 阶段 | 页面做什么 | 用户做什么 | AI 做什么 |
| --- | --- | --- | --- |
| 📖 阅读原文 | 原文拆成段落，一次一段；「只看重点」只显示关键句 | 每段用自己的话总结一句（可选记录） | 无 AI 调用 |
| 🧠 验证理解 | 出一个闭卷验证任务（区分概念/定义/文章等文本类型，难度 1–3） | 凭记忆作答 | 分析作答 → Learner State（理解层级 surface/relationship/application/essence + 已懂/待懂/误区） |
| 💡 最小干预 | 只有存在真实缺口才干预；干预按阶梯递进（提示→例子→类比→反例→直问） | 跟着提示用自己的话回答 | 更新 Learner State；缺口消失或连续 2 次干预无效 → 完成 |
| ✅ 完成 | 自动生成总结（breakthrough + plain + tomorrow_hook） | 查看总结 | 生成总结、streak +1、加入明日复习队列 |
| 🔄 需要重新学习 | 连续 3 次验证不通过 | 回看原文再试一次 | 标记 needs_relearning |

关键规则：

- **验证过即完**：验证通过（无理解缺口）直接进入完成，不强迫用户选择「是否深入」。
- **只在缺口处干预**：无缺口不啰嗦；`LearnerState.has_gap()` 判定 `uncertain / misconceptions` 非空才干预。
- **连续 2 次无效干预直接完成**（`INEFFECTIVE_LIMIT = 2`），不浪费用户时间。
- 每次验证前有 30% 概率（`CONFIDENCE_PROMPT_RATE = 0.3`）让用户先预判自己能否解释清楚（元认知）。

### 4.2 旧流程（保留，`RECALLOS_NEW_FLOW=0` 时启用）

四层追问：核心 → 重要 → 反事实 → 连接（`MAX_LAYER = 4`）。答错降级：第一次简化问题，第二次换角度，第三次答错标记「模糊」并给参考解释。结束后进入连接推荐 + 手动总结。

## 5. 功能清单

### 5.1 首页（`render_home`）

- **今日复习入口**：有到期复习时显示「📝 今日复习（N）」。
- **继续学习入口**：有「学习中」概念时显示「📖 继续学习：{标题}」。
- **精选概念两栏布局**：左栏精选概念卡片（点即开始），右栏自定义输入。
- **自定义学习**：概念名 + 粘贴原文 + 学习目标（理解/联系/应用/考试，可选）+ 预热按钮。
- **详情页信息**：昨天搞懂了什么、连续学习第 N 天（streak）。
- **首次打开推荐**：未学过任何概念时，提示从第一个精选概念开始。

### 5.2 学习页（`render_learning` → `_render_learning_new`）

- **阅读原文**：分段阅读、进度条、只看重点、每段一句总结、我读完了。
- **验证理解**：可回看原文、可点「我看不懂，帮我解释」。
- **最小干预**：AI 决策干预气泡，遇到 AI 失败有「重试」兜底。
- **完成/重新学习**：完成提示 + 查看今日总结；连续 3 次失败进入重新学习。

### 5.3 复习（`render_review_list` / `render_review`）

- 到期概念列表（掌握度标签），点「开始复习」进入。
- AI 出题（优先用上次总结的 `tomorrow_hook`）。
- 答对立即通过；答错连问，最多 3 次；3 次全错 → 该概念标记为「学习中」需重新学习。
- 通过 → master「搞懂了」，间隔按 `2**stage` 天推后（上限 7 天）；失败 → 「模糊」，明天再复习。

### 5.4 今日总结（`render_summary`）

- 自动生成 3 段式总结：**你搞懂了什么** / **说白了我就是** / **明天 AI 会问你**。
- 连续学习天数 +1（当天未生成过总结时）。
- 展示累计掌握概念数与连接数。
- 可选的「继续深入追问」与「查看相关概念」。

### 5.5 我的知识（`render_history`）

- 按掌握度分三组表格：✅ 搞懂了 / 🔄 模糊 / 📖 学习中。
- 行内「查看 / ✕ 删除」，删除带两步确认与级联清理说明。
- 行内展开详情：学习记录（追问 / 验证 / 干预 / 深化）、连接、每日总结、修改自己的理解。

### 5.6 用量统计（`render_usage_stats`）

- 今日 / 本月 / 累计 Token 与成本（按 DeepSeek 公开价估算）。
- 近 7 天消耗趋势表。

### 5.7 API Key 配置

- 首次使用引导页 `render_api_key_setup`：保存自备 Key（仅存本机 `~/.recallos/config.json`）。
- 侧边栏「重新配置 API Key」`render_reconfigure`。
- V1.0：配置 `RECALLOS_WORKER_URL` 后可走 Cloudflare Worker 动态 Key 分发（见技术文档）。

## 6. 内置精选概念（`core/builtin_concepts.py`）

| id | 标题 | 分类 | 难度 |
| --- | --- | --- | --- |
| opportunity_cost | 机会成本 | 经济学 | 1 |
| compound_interest | 复利 | 理财 | 1 |
| survivorship_bias | 幸存者偏差 | 思维模型 | 2 |
| marginal_utility | 边际效用 | 经济学 | 2 |
| sunk_cost | 沉没成本 | 思维模型 | 1 |

每个概念自带约 200 字自足原文 + 一句话 hook，可直接走「阅读 → 验证」新流程。

## 7. 复习调度规则（`core/review.py`）

- 学习完成（任一流程）即加入复习队列，**次日**到期。
- 间隔：`gap = min(7, 2**stage)` 天（stage 从 1 递增 → 2、4、7…）。
- 通过：stage+1、count+1、mastery→搞懂了、next_review_date 按间隔推后。
- 失败：stage 归 0、count+1、mastery→模糊、next_review_date→明天。
- 单次复习 3 次全错：mastery→学习中、`needs_relearn=True`，建议重新学。

## 8. 学习目标（可选输入，`LEARNING_GOALS`）

用户可在首页选择本次目标：🧠 理解概念 / 🔗 建立联系 / 🛠 能实际应用 / 🎓 为考试掌握。该目标进入 Learner State，影响后续干预与深化追问。

## 9. 非功能需求

- **无配置即可用**：首次打开依赖 API Key 或 Worker 分发；配置后 Zero-config 体验。
- **离线/失败兜底**：所有 AI 调用带超时（30s）、有限重试（2 次，仅瞬时错误）、可重试 UI；AI 不可用时验证可手动跳过。
- **成本可控**：每设备每日 Key 请求限额 20 次（Worker KV）；模型定价表驱动估算。
- **数据本地化**：SQLite 存本地；Key 只存本机；不传用户原文到第三方（除 DeepSeek API）。
- **桌面可用**：PyInstaller 单文件打包，数据落到本机 `~/.recallos/data`，windowed 模式日志重定向。
